HOVER TRANSLATE — SAU KHI CÀI ĐẶT
==================================

App đã cài xong, đã kèm sẵn Python — không cần cài gì thêm để chạy.

LẦN ĐẦU DÙNG (cần mạng 1 lần để tải model dịch offline):
  Bấm Alt+Shift+S để mở Cài đặt -> mục "Model Manager" -> bấm "Cài đặt" ở
  dòng Translation (Argos EN<->VI, ~150MB). Sau lần tải này, dịch offline
  hoạt động vĩnh viễn không cần mạng nữa.

  Nếu muốn dùng Live Translate (Alt+L), làm tương tự với dòng Whisper trong
  Model Manager (~75MB cho model Tiny).

PHÍM TẮT NHANH:
  Giữ Alt + rê chuột vào chữ  -> dịch ngay
  Alt+Q   -> chụp vùng màn hình để OCR + dịch
  Alt+T   -> khung dịch nhanh (gõ/dán chữ)
  Alt+L   -> Live Translate (nghe audio hệ thống hoặc mic, dịch gần realtime)
  Alt+Shift+S -> mở Cài đặt
